# بریف ساخت سایت آتیه آمار پژوهان پارسیان روی وردپرس (برای Claude Code)

> این فایل را در ریشه پروژه کنار `CLAUDE.md` بگذارید و به Claude Code بگویید: «بریف را بخوان و فاز ۱ را شروع کن.»

## ۱. معرفی پروژه
- شرکت: **آتیه آمار پژوهان پارسیان** (اصفهان)
- خدمات واقعی (فقط این دو، چیز دیگری اضافه نشود):
  1. **پلاک کدپستی**: تولید، نصب میدانی، بهنگام‌سازی نشانی و کدپستی، کنترل کیفیت نصب
  2. **آرشیو دیجیتال اسناد**: اسکن عمده اسناد سازمانی، نمایه‌سازی و فهرست‌نویسی، بازیابی، ذخیره امن
- خدماتی که شرکت **ندارد**: پلاک درختی، فضای سبز، نرم‌افزار مدیریت شهری، GIS، پکیج شهر هوشمند.
- مشتریان: شهرداری‌ها و سازمان‌ها (اصفهان، افوس، نجف‌آباد، خمینی‌شهر و ...)
- سایت فعلی شرکت (amarpp.com) فقط صفحه «درخواست خدمات» دارد با لینک‌های: همکاری با ما، درخواست خدمات، تماس با ما، درگاه پرداخت. همه این‌ها باید در سایت جدید باشند.
- موکاپ مرجع: https://claude.ai/artifact/78QVJucjf4Qshz3mM2fQxG (فایل `Main.dc.html`؛ از آن فقط چیدمان، رنگ و حرکت را الگو بگیرید، کد آن وردپرسی نیست.)

## ۲. محیط محلی
- ترجیح: Docker (`wp-env` یا docker-compose با `wordpress` و `mariadb`) یا LocalWP.
- وردپرس آخرین نسخه، PHP 8.2+، زبان فارسی، جهت RTL، منطقه زمانی Asia/Tehran، تقویم شمسی (افزونه یا تابع کمکی).
- قالب سفارشی **block theme** (theme.json، بدون page builder) با نام `atiyeh`. اگر block theme برای بخش‌های انیمیشنی دست‌وپاگیر شد، قالب کلاسیک سبک با `functions.php` مجاز است؛ در این صورت دلیلش را در README بنویس.
- Git از روز اول؛ کامیت‌ها کوچک و فاز به فاز.

## ۴. بخش‌های صفحه اصلی (به ترتیب)
1. **هدر شناور** (گلس‌مورفیسم): لوگو، منو (درباره ما، خدمات، خدمات اصلی، پروژه‌ها، حسن انجام کار، اخبار، تماس، درگاه پرداخت)، دکمه «درخواست دمو/مشاوره».
2. **اسلایدر هیرو، ۳ اسلاید** (خودکار هر ۵.۵ ثانیه، نقطه‌ها، فلش، شمارنده، توقف با hover و تمرکز، قابل استفاده با کیبورد):
   - پلاک کدپستی، نشانی دقیق هر ملک
   - اسناد سازمان شما، دیجیتال و در دسترس (تصویر: الگو + دسته اسناد با خط اسکن متحرک)
   - بهنگام‌سازی کدپستی در سراسر شهر
3. **نوار مورد اعتماد کارفرمایان** (مارکی بی‌نهایت): لوگوها در کادر سفید هم‌اندازه ۲۰۰×۹۲ با `object-fit: contain`؛ لوگوهای شهرداری اصفهان، افوس، نجف‌آباد، خمینی‌شهر + جای خالی برای بقیه. نوع محتوا: CPT «کارفرما».
4. **درباره شرکت**: متن معرفی (جایگزین)، چهار لینک: معرفی شرکت، تیم مدیریت، مجوزها و رتبه‌بندی‌ها، چارت سازمانی.
5. **خدمات** (۸ کارت با ریتم ناهم‌تراز): تولید پلاک، نصب میدانی، بهنگام‌سازی کدپستی، کنترل کیفیت نصب، اسکن عمده اسناد، نمایه‌سازی و فهرست‌نویسی، سامانه بازیابی اسناد، ذخیره‌سازی امن و پشتیبان. *(زیرخدمات پیشنهادی است؛ با کارفرما تأیید شود.)*
6. **خدمات شاخص** (بخش تیره bento): کارت بزرگ «پلاک کدپستی»، کارت «آرشیو دیجیتال اسناد»، سه کارت کوچک.
7. **آمار** (دایره‌های هم‌پوشان، شمارنده متحرک): پلاک نصب‌شده، سند اسکن‌شده، کارفرمای فعال، سال تجربه. مقدارها فعلاً `[ ۰۰ ]` (باید از شرکت گرفته شود).
8. **روش کار** (۴ گام): ثبت درخواست، طراحی و برنامه‌ریزی، اجرا، گزارش و تحویل.
9. **پروژه‌های شاخص** (کارت‌های قوسی، فیلتر: همه / پلاک کدپستی / آرشیو دیجیتال / بهنگام‌سازی).
10. **حسن انجام کار** (تصویر لوح‌ها + دکمه گالری لوح‌های سپاس).
11. **اخبار** (لیست + سایدبار گزیده اخبار).
12. **درخواست خدمات**: فرم (نام، سازمان، تلفن، نوع خدمت، توضیح) + دکمه درگاه پرداخت + همکاری با ما.
13. **همکاری با ما**: بنر + چیپ عناوین شغلی: نصاب پلاک کدپستی، بازرس میدانی، اپراتور اسکن، کارمند نمایه‌سازی، بازاریاب و ویزیتور.
14. **فوتر**: معرفی کوتاه، دسترسی سریع، تماس (آدرس، تلفن، ایمیل)، خبرنامه.

## ۵. ساختار محتوا در وردپرس
- **Custom Post Types** (با `show_in_rest`):
  - `project` (پروژه): فیلدها: کارفرما، شهر، نوع خدمت (taxonomy `service`: پلاک کدپستی، آرشیو دیجیتال، بهنگام‌سازی)، تاریخ، تصویر شاخص
  - `client` (کارفرما): لوگو (تصویر شاخص)، نام، لینک
  - `appreciation` (لوح سپاس): تصویر، کارفرما، سال
  - `job` (فرصت شغلی): عنوان، شرح، شهر، فعال/غیرفعال
- **پست‌های معمولی** برای اخبار.
- صفحه‌ها: خانه، درباره ما (با چهار زیرصفحه)، خدمات، پروژه‌ها، حسن انجام کار، اخبار، همکاری با ما، درخواست خدمات، تماس با ما.
- فیلدها: ACF Free یا `register_post_meta` بومی. ترجیح با بومی تا وابستگی کم باشد.
- لوگوهای کارفرما: همه را هنگام آپلود روی بوم سفید هم‌اندازه (۴۸۰×۲۲۰) نرمال کن (hook روی `wp_generate_attachment_metadata` یا اسکریپت وارد کردن).

## ۶. فرم‌ها و درگاه
- فرم درخواست خدمات و فرم تماس: ساخت دستی (admin-post + nonce + honeypot + محدودیت نرخ) یا Contact Form 7 / Fluent Forms. ذخیره در پایگاه داده و ایمیل به مدیر.
- فرم همکاری با ما: آپلود رزومه (pdf/docx، حداکثر ۵ مگابایت، اعتبارسنجی نوع فایل).
- درگاه پرداخت: لینک/صفحه جدا؛ **درگاه واقعی را متصل نکن** تا شرکت درگاه و مجوز آن را مشخص کند. فقط صفحه و دکمه.

## ۷. سئو، سرعت، دسترسی
- افزونه سئو: Rank Math یا Yoast با زبان فارسی؛ `lang="fa" dir="rtl"`؛ schema نوع `Organization` و `LocalBusiness`.
- تصاویر WebP، `loading="lazy"` به‌جز هیرو، اندازه‌های responsive (`srcset`).
- بدون jQuery اضافه؛ جاوااسکریپت کم و ماژولار.
- کنتراست رنگ حداقل AA، فوکوس قابل‌دیدن، متن جایگزین تصاویر، برچسب برای همه فیلدها.
- ریسپانسیو: ۳۲۰ تا ۱۴۴۰ پیکسل؛ در موبایل شبکه‌ها یک‌ستونه و چیدمان ناهم‌تراز خاموش شود.

## ۸. تصاویر
- تصاویر موکاپ (پل خواجو، بازار، تیم، لوح‌ها، پلاک کدپستی، نقشه‌برداری) با هوش مصنوعی ساخته شده‌اند و **موقتی‌اند**؛ در نسخه نهایی با عکس‌های واقعی شرکت جایگزین شوند.
- تصویر مناسب برای «آرشیو دیجیتال» هنوز ساخته نشده (هیرو اسلاید ۲ فعلاً الگوی گره‌چینی + دسته اسناد CSS دارد).
- تصاویر منبع را از کاربر بگیر؛ لینک‌های `/_blob/...` موکاپ بیرون از آن کار نمی‌کنند.

## ۹. فازبندی پیشنهادی
1. **فاز ۱:** راه‌اندازی محیط محلی، قالب خالی، توکن‌ها، فونت، هدر و فوتر، RTL.
2. **فاز ۲:** صفحه اصلی بخش به بخش (هیرو، مارکی، درباره، خدمات، bento، آمار، روش کار).
3. **فاز ۳:** CPTها، آرشیوها و صفحات تکی، فیلتر پروژه‌ها.
4. **فاز ۴:** فرم‌ها، همکاری با ما، درگاه (صفحه).
5. **فاز ۵:** سئو، سرعت، دسترسی، تست مرورگرها، مستندات استقرار (`README.md`).
- بعد از هر فاز: اسکرین‌شات در عرض ۱۴۴۰ و ۳۹۰ بگیر و با موکاپ مقایسه کن.

## ۱۰. محتوای جایگزین (برای پر کردن توسط شرکت)
