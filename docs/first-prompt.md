بریف docs/wordpress-build-brief.md و CLAUDE.md را کامل بخوان، سپس اسکرین‌شات‌های docs/mockup/screens را ببین. پوشه theme/ شامل قالب آماده‌ای است که من دارم؛ ساختار و فایل‌هایش را بررسی کن و تصمیم بگیر از آن شروع کنیم یا قالب `atiyeh` را از صفر بسازیم (دلیلت را بگو).

هدف: یک سایت وردپرس کاملاً لوکال برای دموی حضوری که شبیه موکاپ باشد، بدون نیاز به اینترنت.

مرحله صفر (قبل از نوشتن کد):
1. بررسی کن Docker، Node، Git و npm روی سیستم هست یا نه. اگر Docker نبود، بگو و از LocalWP + WP-CLI استفاده کن.
2. یک طرح کوتاه بده: ساختار پوشه‌ها، روش اجرای وردپرس (wp-env یا docker-compose)، لیست افزونه‌ها (Fluent Forms، Rank Math، WP-Parsidate، All-in-One WP Migration)، و فازبندی. صبر کن تأیید کنم.

بعد از تأیید:
- فاز ۱: محیط لوکال با وردپرس فارسی، RTL، منطقه زمانی تهران، یک دستور واحد برای بالا آوردن سایت (`npm run start`) و یک دستور ریست دمو (`npm run reset-demo`) که محتوای نمونه را دوباره می‌سازد.
- قالب با توکن‌های بریف، فونت Vazirmatn محلی (از npm بیاور)، هدر و فوتر.
- فاز ۲: صفحه اصلی بخش به بخش مطابق موکاپ، با تصاویر assets-source (راهنما در assets-source/README.md؛ تصاویر «استفاده نشود» را به‌کار نبر).
- فاز ۳: پست‌تایپ‌ها (project، client، appreciation، job) و taxonomy خدمات، محتوای نمونه با WP-CLI، فیلتر پروژه‌ها.
- فاز ۴: فرم‌ها (درخواست خدمات، همکاری با ما، تماس) با ذخیره در پایگاه داده. صفحه درگاه پرداخت فقط صفحه و دکمه.
- فاز ۵: سئو پایه، دسترسی، ریسپانسیو، تست در عرض ۱۴۴۰ و ۳۹۰.

قوانین:
- بعد از هر فاز کامیت کن، اسکرین‌شات بگیر، با موکاپ مقایسه کن و تفاوت‌ها را دقیق بگو.
- هر چیزی که مطمئن نیستی را بپرس؛ محتوا یا عدد از خودت نساز.
- در پایان README.md بنویس: چطور سایت را روی سیستم دیگر بالا بیاورم و چک‌لیست قبل از جلسه دمو.
