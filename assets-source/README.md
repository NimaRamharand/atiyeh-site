# راهنمای تصاویر و لوگوها

همه فایل‌ها WebP بهینه‌شده‌اند. تصاویر با هوش مصنوعی ساخته شده‌اند و **موقتی‌اند** (بعداً با عکس‌های واقعی شرکت جایگزین می‌شوند). نام فایل‌ها را در کد ثابت نگه دار تا جایگزینی آسان باشد.
