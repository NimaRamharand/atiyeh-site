## logos/
لوگوی کارفرمایان (از شرکت، آبان ۱۴۰۵)، همه با یک قاعده آماده شده‌اند:
- روی بوم سفید ۴۸۰×۲۲۰، حاشیه‌های خالی بریده شده، و هم‌وزن بصری (لوگوهای پهن حداکثر ۳۲۰ پیکسل).
- WebP با کیفیت ۹۰.
- لوگویی که اپراتور در پیشخوان برای کارفرما انتخاب کند، خودکار با همین قاعده آماده می‌شود (`atiyeh-core/inc/logo-normalize.php`).
