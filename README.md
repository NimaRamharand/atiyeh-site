# سایت آمار پژوهان پارسیان

سایت وردپرسی شرکت آمار پژوهان پارسیان (اصفهان) با این بخش‌ها:
- **خدمات:** پلاک کدپستی، آرشیو الکترونیک اسناد، آمار و داده، مشاوره و تأمین اسکنر، خدمات انفورماتیک
- **محتوا:** کارفرمایان، پروژه‌ها، لوح‌های سپاس، اسلاید مناسبتی، فرصت‌های شغلی با ارسال رزومه، فرم‌های درخواست و تماس

**مشخصات فنی:**
- راست‌چین (RTL)، فونت وزیرمتن محلی، حالت روز و شب
- بدون هیچ منبع خارجی در زمان اجرا

| بخش | محل |
|---|---|
| قالب | `wp-content/themes/atiyeh` |
| افزونه اختصاصی (انواع محتوا، فرم‌ها، رزومه‌ها، اسلاید مناسبتی) | `wp-content/plugins/atiyeh-core` |
| محتوای نمونه | `scripts/wp/seed*.php` |
| تصاویر و فایل‌های مرجع | `assets-source/` (رزومه شرکت: `assets-source/files/`) |
| آنالیز کلمات کلیدی | `docs/seo/keyword-analysis.md` |
| اسکرین‌شات‌ها | `docs/screens/` |

## ۱. اجرا روی یک سیستم تازه

**پیش‌نیازها:**
- [Docker Desktop](https://www.docker.com/products/docker-desktop)؛ باز و در وضعیت «Engine running»
- [Node.js](https://nodejs.org) نسخه ۱۸ یا بالاتر
- Git

**بار اول** (چند دقیقه طول می‌کشد، چون WordPress و MariaDB دانلود می‌شوند):
```bash
git clone https://github.com/nimaramharand/atiyeh-site.git
cd atiyeh-site
npm install
npm run start
```

**ورود:**
- سایت: http://localhost:8093
- پیشخوان: http://localhost:8093/wp-admin
- نام کاربری `admin`، رمز `atiyeh-demo`

اگر پورت 8093 اشغال بود، قبل از `npm run start` یک پورت آزاد دیگر بدهید:
- PowerShell: `$env:ATIYEH_PORT="8094"`
- bash: `export ATIYEH_PORT=8094`

| دستور | کار |
|---|---|
| `npm run start` | روشن کردن سایت (بار اول نصب کامل و ساخت محتوا) |
| `npm run stop` | خاموش کردن؛ داده‌ها می‌مانند |
| `npm run reset-demo` | پاک کردن و ساخت دوباره محتوای نمونه |
| `npm run destroy` | حذف کامل سایت و دیتابیس |

**به‌روزرسانی** بعد از تغییرات جدید:
```bash
git pull origin main
npm run reset-demo
```

> ⚠️ **`reset-demo` همه محتوایی را که خودِ اسکریپت ساخته از نو می‌سازد.** این شامل صفحه‌ها، منوها، پروژه‌ها، کارفرمایان، لوح‌ها، آگهی‌ها و اسلایدهای مناسبتی است. اگر یکی از این‌ها را در پیشخوان ویرایش کرده باشید، تغییرتان از بین می‌رود.
> ورودی فرم‌ها، رزومه‌ها، اعضای خبرنامه و مطالبی که خودتان از اول ساخته‌اید پاک **نمی‌شوند**.
> **روی هاست اصلی هرگز `reset-demo` نزنید.**

**اگر به مشکل خوردید:**
- **خطای `docker` پیدا نشد / `cannot connect`:** Docker Desktop را باز کنید و صبر کنید تا «Engine running» شود.
- **خطای `pull access denied` / `403` / timeout:** Docker Hub در دسترس نیست. یکی از این دو کار را بکنید:
  - فقط بار اول VPN را روشن کنید.
  - یا در Docker Desktop به Settings ← Docker Engine بروید و `"registry-mirrors": ["https://docker.arvancloud.ir"]` را اضافه کنید.
- **خطای «وردپرس در زمان مقرر بالا نیامد»:** دوباره `npm run start` بزنید. اگر باز هم خطا داد، خروجی `docker compose logs --tail 50` را بررسی کنید.

حالت سبک بدون Docker (`npm run start:lite`) فقط برای توسعه است و روی ویندوز پشتیبانی نمی‌شود.

## ۲. راهنمای اپراتور: هر چیز را کجا عوض کنیم

| چه چیزی | کجا در پیشخوان |
|---|---|
| **اسلاید اول صفحه اصلی** (مناسبت، رویداد، خبر مهم) | **اسلاید مناسبتی** ← افزودن اسلاید |
| کارفرمایان (لوگو، شهر، نوع خدمت) | **کارفرمایان**؛ ۱۰ مورد اول در نوار صفحه اصلی نمایش داده می‌شوند |
| پروژه‌ها (کارفرما، شهر، تاریخ، وضعیت «در حال اجرا»، نوع خدمت) | **پروژه‌ها**؛ ۳ مورد اول در صفحه اصلی می‌آیند |
| لوح‌های سپاس | **لوح‌های سپاس** |
| آگهی‌های شغلی | **فرصت‌های شغلی**؛ تیک «آگهی فعال است» |
| رزومه‌های دریافتی | **فرصت‌های شغلی ← درخواست‌های همکاری**؛ دانلود فقط برای مدیر |
| پیام‌های فرم درخواست خدمات و تماس | **فرم‌های فلوئنت ← ورودی‌ها** |
| اعضای خبرنامه | **خبرنامه** |
| آدرس، تلفن، ایمیل، مدیرعامل، شماره ثبت، **فایل رزومه PDF** | **نمایش ← سفارشی‌سازی ← اطلاعات تماس شرکت** |
| چهار عدد دایره‌ای صفحه اصلی | **نمایش ← سفارشی‌سازی ← آمار صفحه اصلی** |
| لوگو و فاوآیکن (در صورت تغییر) | **نمایش ← سفارشی‌سازی ← هویت سایت** |
| منوی بالا و فوتر | **نمایش ← فهرست‌ها** |
| متن اول صفحه‌ها (درباره ما، معرفی شرکت و…) | **برگه‌ها** |
| عنوان و توضیح هر صفحه برای گوگل | ویرایش برگه ← جعبه **Rank Math** |

**قانون اسلاید مناسبتی:**
- جدیدترین اسلاید منتشرشده‌ای که امروز در بازه نمایشش باشد، اسلاید اول می‌شود. تاریخ‌ها شمسی‌اند، مثل `۱۴۰۵/۰۸/۰۱`.
- اسلایدهای قبلی پاک نمی‌شوند و با وضعیت «آرشیو» می‌مانند.
- اگر هیچ اسلاید فعالی نباشد، اسلایدر بدون آن نمایش داده می‌شود.

**این متن‌ها در کد قالب‌اند و تغییرشان کار برنامه‌نویس است:**
- متن خدمات و پرسش‌های متداول
- مجوزها
- چارت سازمانی
- متن بخش‌های صفحه اصلی

## ۳. چک‌لیست قبل از جلسه دمو

- [ ] Docker Desktop باز است و «Engine running» نشان می‌دهد.
- [ ] `git pull origin main`، بعد `npm run start` و بعد `npm run reset-demo` بدون خطا تمام شد.
- [ ] http://localhost:8093 باز شد. یک بار **Ctrl+F5** زده شد تا لوگو و فاوآیکن تازه شوند.
- [ ] اسلاید اول همان مناسبتی است که می‌خواهید نشان دهید (پیشخوان ← اسلاید مناسبتی).
- [ ] دکمه ماه و خورشید کنار جستجو حالت شب را درست نشان می‌دهد. **قبل از جلسه به حالت روز برگردانده شد.**
- [ ] صفحه‌های اصلی یک بار باز شدند تا جلسه کند نباشد:
  - [ ] درباره ما
  - [ ] خدمات
  - [ ] کارفرمایان (فیلتر)
  - [ ] پروژه‌ها
  - [ ] همکاری با ما
  - [ ] تماس
- [ ] یک فرم درخواست خدمات آزمایشی ارسال و در «فرم‌های فلوئنت ← ورودی‌ها» دیده شد. **بعد از جلسه پاک شود.**
- [ ] دانلود رزومه PDF از صفحه معرفی شرکت کار می‌کند.
- [ ] پیشخوان در یک تب جدا باز است و نام کاربری و رمز در دسترس است.
- [ ] زوم مرورگر روی ۱۰۰٪ است و افزونه‌های مزاحم مرورگر خاموش‌اند.
- [ ] برای نمایش موبایل: F12 ← Toggle device ← عرض ۳۹۰.

## ۴. انتقال به هاست (amarpp.com)

سایت با افزونه **Duplicator** از نسخه Docker به هاست منتقل می‌شود. انتقال از حالت سبک (SQLite) کار نمی‌کند.

**پیش‌نیاز روی هاست** (cPanel یا DirectAdmin):
- PHP نسخه 8.2 یا 8.3
- MySQL یا MariaDB
- SSL فعال برای `amarpp.com`
- محدودیت آپلود حداقل ۸ مگابایت

### الف) ساخت بسته روی سیستم خودتان
1. سایت را با `npm run start` روشن کنید. **دیگر `reset-demo` نزنید**، مگر اینکه بخواهید همه ویرایش‌های پیشخوان از بین برود.
2. در پیشخوان به **Duplicator ← Backups** بروید (در نسخه‌های قدیمی: Packages) و **Add New** را بزنید. Scan و Build را اجرا کنید.
3. دو فایل را دانلود کنید: **installer.php** و **فایل آرشیو (zip)**.

### ب) نصب روی هاست
1. در کنترل پنل یک **دیتابیس MySQL** و یک **کاربر** بسازید، کاربر را به دیتابیس وصل کنید و همه دسترسی‌ها را به آن بدهید. نام دیتابیس، کاربر و رمز را یادداشت کنید.
2. با File Manager، هر دو فایل را در **public_html** آپلود کنید. پوشه باید خالی باشد.
3. در مرورگر `https://amarpp.com/installer.php` را باز کنید.
4. اطلاعات دیتابیس را وارد کنید. آدرس سایت باید `https://amarpp.com` باشد.
5. بعد از پایان، وارد پیشخوان شوید. Duplicator پیشنهاد حذف فایل‌های نصب را می‌دهد؛ **حتماً حذف کنید.**

### ج) تنظیمات بعد از انتقال (حتماً)
- [ ] **فایل `wp-config.php` روی هاست را ویرایش کنید.** این سطرها مخصوص اجرای آفلاین‌اند و باید **حذف** شوند:
  ```php
  define('WP_HTTP_BLOCK_EXTERNAL', true);
  define('WP_ACCESSIBLE_HOSTS', 'localhost');
  define('AUTOMATIC_UPDATER_DISABLED', true);
  define('WP_AUTO_UPDATE_CORE', false);
  ```
  و `WP_ENVIRONMENT_TYPE` را از `'local'` به `'production'` تغییر دهید. سطر `DISALLOW_FILE_EDIT` بماند.
- [ ] **رمز کاربر `admin` را عوض کنید** (کاربران ← پروفایل). رمز `atiyeh-demo` عمومی است.
  - برای اپراتور یک کاربر جدا با نقش «ویرایشگر» بسازید.
- [ ] ایمیل مدیر در **تنظیمات ← عمومی** را به `contact@amarpp.com` تغییر دهید.
- [ ] **تنظیمات ← خواندن:** تیک «از موتورهای جستجو بخواهید…» را **بردارید**. در نسخه لوکال عمداً روشن است.
- [ ] **تنظیمات ← پیوندهای یکتا:** یک بار «ذخیره» بزنید.
- [ ] صندوق ایمیل `contact@amarpp.com` را در کنترل پنل بسازید. یک فرم تماس آزمایشی بفرستید و ببینید اعلانش می‌رسد. اگر نرسید، یک افزونه SMTP نصب کنید.
- [ ] افزونه‌ها و وردپرس را به‌روز کنید.
- [ ] پشتیبان‌گیری خودکار هفتگی را در کنترل پنل فعال کنید (مثلاً JetBackup).

### د) معرفی به گوگل
- [ ] سایت را در [Google Search Console](https://search.google.com/search-console) ثبت کنید. نقشه سایت را بدهید: `https://amarpp.com/sitemap_index.xml`
- [ ] صفحه کسب‌وکار در **Google Business Profile** و **نشان** بسازید (نشانی و تلفن یکسان با سایت).
- [ ] بعد از چند هفته، داده واقعی جستجو از Search Console برای مرحله بعد سئو استفاده شود (`docs/seo/keyword-analysis.md`).

## ۵. یادداشت‌های فنی

- **ساختار:** قالب ترکیبی است؛ رنگ‌ها و فونت در `theme.json` و قالب‌ها PHP. انیمیشن‌ها در `assets/css/motion.css` و `assets/js/main.js`.
  - همه انیمیشن‌ها با تنظیم «کاهش حرکت» سیستم‌عامل خاموش می‌شوند.
- **اسکیما:**
  - Rank Math صفحه‌ها، نقشه سایت و مسیر صفحه (BreadcrumbList) را می‌سازد.
  - قالب، موجودیت سازمان (Organization و ProfessionalService) را از اطلاعات سفارشی‌سازی پر می‌کند: `inc/seo.php`.
  - اتصال حساب Rank Math عمداً رد شده تا سایت آفلاین هم کار کند.
- **دسترس‌پذیری:**
  - با axe-core روی همه صفحه‌ها در حالت روز و شب بررسی شده: صفر خطا.
  - کنتراست رنگ‌ها بالای حد WCAG AA است.
  - تمام سایت با کیبورد قابل استفاده است و فوکوس همیشه دیده می‌شود.
- **فایل رزومه منتشرشده:** شماره تماس دو نفر از کارکنان بیمارستان‌ها از آن حذف شده است.
